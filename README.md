# 🍎 Fruit Classification Using Decision Tree

A beginner-friendly Machine Learning project that uses a **Decision Tree Classifier** to classify fruits based on their **weight, color, and texture**.

## 📌 Project Overview

The model is trained to classify four types of fruits:

* 🍎 Apple
* 🍊 Orange
* 🍌 Banana
* 🥭 Mango

This project demonstrates **Supervised Learning and Classification** using a simple fruit dataset.

## 🧠 How It Works

The model learns from:

* **Features:** Weight, Color, Texture
* **Labels:** Apple, Orange, Banana, Mango

After training, the model receives new fruit data and predicts its fruit type.

**Training Data → Model Training → New Fruit → Prediction**

## 🛠️ Technologies

* Python
* Scikit-learn
* Matplotlib
* NumPy
* Jupyter Notebook / Google Colab

## 📊 Dataset

The project uses a small manually created dataset containing **15 fruit samples**.

Color and texture are represented using numerical values so that the Machine Learning model can process them.

## 🌳 Decision Tree Visualization

The trained Decision Tree is visualized using Matplotlib and Scikit-learn.

The visualization helps understand how the model makes decisions using conditions such as **Weight ≤ 140** or **Color ≤ 1.5**.
